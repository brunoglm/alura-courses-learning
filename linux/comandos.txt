Sessões
  iniciar sessão como root no terminal
    sudo -i

  Abre uma sessão de shell como usuário root, mantendo o ambiente do usuário atual
    sudo su


Naveção e acesso de arquivos
  voltar para home do usuário atual
    cd ~ ou cd

  listando todos os arquivos, incluindo ocultos
    ls -a

  listando arquivos com detalhes
    ls -l

    detalhando permissões
      d rwx rwx rwx
      - rwx rwx rwx

      primeiro caractere
        d → diretório
        - → arquivo

      proximos 9 caracteres
        rwx → permissões do dono do arquivo
        rwx → permissões do grupo do arquivo
        rwx → permissões de outros usuários

        onde estiver - não há permissão

      representação numérica das permissões
        r → 4
        w → 2
        x → 1

        exemplo: rwx rwx r-- → 774

      mudando o acesso de um arquivo ou pasta
        chmod 774 arquivo.txt

        exemplo com pasta e sub-pastas
          chmod -R 774 pasta1/



Diretórios e arquivos
  criar pastas já com sub-pastas
    mkdir -p pasta1/pasta2

  mover arquivos ou pastas
    mv arquivo.txt pasta1/

    caso não estejamos na pasta do arquivo
      mv /home/usuario/arquivo.txt pasta1/

    mover pasta renomeando
      mv pasta1/ pasta2/

  copiar arquivos ou pastas
    cp arquivo.txt pasta1/

    copiar mudando o nome do arquivo
      cp arquivo.txt pasta1/arquivo_copiado.txt

    caso não estejamos na pasta do arquivo
      cp /home/usuario/arquivo.txt pasta1/

    copiando pastas
      cp -r pasta1/ pasta2/

    remover arquivos ou pastas
      rm arquivo.txt

      rm -r pasta1/

      removendo com confirmação
        rm -i arquivo.txt

      removendo pasta vazia
        rmdir pasta1/


escrevendo em arquivos
  redirecionando a saída de um comando para um arquivo. Caso o arquivo não exista, ele será criado. Caso exista, o conteúdo será sobrescrito.
    ls -l > lista.txt

  acrescentando a saída de um comando a um arquivo. Caso o arquivo não exista, ele será criado. Caso exista, o conteúdo será acrescentado ao final do arquivo.
    ls -l >> lista.txt

  escrevendo em um arquivo com o comando echo
    echo "Olá, mundo!" > arquivo.txt
